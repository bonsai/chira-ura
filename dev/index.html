全体構成

拡張（popup / サイドパネル / background）、CLI、SQLite（~/.chira/ura.db）、GDrive の位置づけ。同期の意味はひとつ「GDrive が正」。

書く — 自動保存とコピー

chira-ura-write.svg 生 SVG ソース

本文を入れると 600ms で自動保存。コピーは本文のみ（前置きなし）。保存は title を本文1行目から導出。

同期 — GDrive が正

chira-ura-sync.svg 生 SVG ソース

CLI が localhost:8787 のブリッジにミラーを配り、拡張は 5 分 alarm で pull するだけ。拡張から push はしない。

箱と認証 — OAuth

chira-ura-auth.svg 生 SVG ソース

同じ箱を 2 度押しすると同意画面。トークンはメモリ上かローカルの token.json（0600）。repo には置かない。

メモのデータ — 同じ JSON

chira-ura-data.svg 生 SVG ソース

拡張と CLI は同じ JSON（{id, title, content, updatedAt}）を使う。SQLite と JSONL（箱のファイル形式）でやり取りする。

描画し直す

cd dev
java -jar plantuml.jar -charset UTF-8 -tsvg chira-ura.puml

plantuml.jar は開発用。repo には入れていない（.gitignore 済み）。
