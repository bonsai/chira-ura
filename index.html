チラ裏chira-ura

書いたら自動保存。メモとコピーだけの軽量クライアント群。
入口（UI）は多様に、正はひとつ。

自動保存箱: ローカル / GDrive / GitHub / BoxOAuthMV3オフライン

できること

  • サイドパネルで書く。入力は自動保存（トグルで停止可）。
  • 過去記事を読む。コピーは本文だけ（前置き無し＝そのままプロンプトに流せる）。
  • 箱を選ぶ。ローカル / Google Drive / GitHub / Box。認証は OAuth、トークンは保存しない。
  • オフラインでためて、オンラインでまとめて送る。送信は CLI に集約。

crx — Chrome 拡張

crx/ ・ MV3 / Vanilla JS

インストール

Release から zip crx/ ソース 
1. zip を展開
2. chrome://extensions → デベロッパーモード ON
3. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを指定

特徴

  • sidepanel で書く / 読む。保存は 600ms デバウンスの自動保存。
  • 1分毎チェック + closed 送信（NEW / ページを閉じる / 10分無更新）で /inbox へ。
  • オフライン時は chrome.storage.local に保留し、復帰時に再送。

cli — 設定・同期・wiki push

cli/ ・ bin: chira（Node / node:sqlite）

セットアップ

bash cli/install.sh    # ~/.local/bin/chira（初回だけ）
chira client-id <id>.apps.googleusercontent.com   # OAuth クライアント
chira set gdrive.folderId <id>                    # 箱フォルダ
chira box gdrive                                  # 既定の箱

同期・送信

chira serve        # ブリッジ（拡張が取りに来る）
chira pull|push    # 同期＝GDrive が正
chira sync         # 未送信（SQLite）→ FE API /inbox
chira wiki         # 未送信 → bonsai/wiki raw/（10件ずつ 1 コミット）
chira notes        # メモ一覧（新しい順）
chira note add 本文 # メモを書く（タイトルは1行目から）

送信は CLI に集約。クライアントは ~/.chira/ura.db に保存するだけ（疎結合）。

api — Cloudflare Worker

api/ ・ FE API + cron + MCP

PUT  /inbox/<name>   { content, updatedAt, closed } を KV へ
GET  /inbox          { items, count }（updatedAt 降順）
GET  /count          { count, lastReceivedAt }
POST /mcp            Streamable HTTP MCP（6 tools）
POST /cron/flush     手動で closed → bonsai/wiki へ
scheduled            毎時 0 * * * * でバッチ

認証は API_TOKEN（後方互換 CHIRA_TOKEN）。未設定時は dev 許可。

win — Windows 付箋（C#/.NET）

gui/win/ ・ .NET 10 WinForms ・ exe: chira.exe

使い方

  • 起動すると白紙・すぐ書ける。入力は自動保存（1秒デバウンス）。
  • 下部フッター三等分: 📝 ステータス ｜ ＋（次の白紙） ｜ ✕（終了）。
  • 日本語入力は IME ひらがなを明示。保存時に吹き出しでファイル名を通知。
  • 保存先は ~/.chira/ura.db（CLI と同じ DB）。

ビルド

dotnet build gui/win/ChiraUra.Win/ChiraUra.Win.csproj -c Release
dotnet publish gui/win/ChiraUra.Win -c Release -r win-x64 \
  --self-contained true -p:PublishSingleFile=true -o out

rust — egui GUI

gui/rust/ ・ Rust + eframe（WSL / Unix / Windows）

  • 起動即フォーカスの1画面付箋。コールドスタート→入力可能 約 122ms。
  • ローカル outbox（~/.chira/outbox/<id>.json）→ オンラインで FE API へ。
  • 単一バイナリ配布。ADR-001 の第一候補。
cargo build --release --manifest-path gui/rust/Cargo.toml
./gui/rust/target/release/chira-ura-rs
