チラ裏chira-ura

書いたら自動保存。メモとコピーだけの軽量 Chrome 拡張。
設定画面はありません。書く・読む・コピるだけ。

自動保存箱: ローカル / GDrive / GitHub / BoxOAuthMV3

できること

  • サイドパネルで書く。入力は自動保存（トグルで停止可）。
  • 過去記事を読む。カードを開いて本文、コピーは本文だけ（前置き無し＝そのままプロンプトに流せる）。
  • 箱を選ぶ。ローカル / Google Drive / GitHub / Box。認証は OAuth で、トークンは保存しない。
  • CLI と同期。意味はひとつ「GDrive が正」。CLI が配り、拡張は取りに行くだけ。

インストール

Release から zip ソース 
1. zip を展開
2. chrome://extensions → デベロッパーモード ON
3. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを指定

CLI

chira client-id <id>.apps.googleusercontent.com   # OAuth クライアント
chira set gdrive.folderId <id>                    # 箱フォルダ
chira box gdrive                                  # 既定の箱
chira serve                                       # ブリッジ（拡張が取りに来る）
chira pull | push | sync                          # 同期＝GDrive が正
